# Locutus API Reference

Locutus provides the backend for a web based terminology mapping tool. The goal of the application is to provide a collaborative environment to harmonize dataset terms with public ontologies such as MeSH, HPO and others.

For an overview of the project, local setup and how to run the test suite, see the [repo README](https://github.com/NIH-NCPI/locutus#readme).

This site documents the full REST API, split by resource:

* [Authorization](authorization.md) -- login, sessions, API tokens, institution access, admin endpoints. Every endpoint below also requires the authentication this page describes.
* [Terminology](terminology.md)
* [Table](table.md)
* [Study](study.md)
* [Data Dictionary](datadictionary.md)
* [Ontology API](ontology-api.md)
* [Harmony File End Points](harmony.md)
* [Side Load](sideload.md)
